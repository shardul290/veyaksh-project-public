What this system can handle

The current project software accepts and displays traffic event records. Depending on the footage and event, records may include:

  • vehicle registration plate text and a plate image;
  • traffic images or video clips that may contain vehicles, passengers, pedestrians, or other identifying details;
  • event timestamps, camera and node identifiers, approximate camera locations, vehicle class, event type, and model confidence values.

The local dashboard requests node and event data from this project's API and loads media from its /media/ path. The current development API has no authentication. It must not be exposed to the public internet until access controls, hosting security, and operational responsibilities have been reviewed.

Map provider

The dashboard loads the Leaflet map library from unpkg.com and requests visible map tiles directly from the OpenStreetMap tile service. These requests are made by your browser and include standard connection information such as your IP address, browser details, and the referring page. Tile requests also indicate the map area being viewed. Event and plate values are not included in those requests. Review the OpenStreetMap Foundation privacy policy and the policies of the services used to deliver Leaflet assets.
